Section 01 • Introduction & Objectives Slide 04 / 16

Core Project Objectives

Four engineering and scientific milestones delivered by NewsScope

1. Zero Data Leakage Pipeline

Strict isolation between training and testing data. The 10,000-word vocabulary and IDF weights are calculated solely on train folds; test sets are treated strictly as unseen incoming streams.

2. 4-Model Architecture Benchmark

Systematically compare 4 distinct machine learning paradigms on identical data: Naive Bayes (probability), Linear SVM (geometry), MLP (neural net), and DistilBERT (transformer).

3. Model Interpretability & Saliency

Extract top keyword contributions via hyperplane dot-product weights (w^T · x) and present calibrated confidence percentages using Platt scaling.

4. Production Full-Stack Web Platform

Deliver a responsive, decoupled web system featuring real-time single inference, a 4-model parallel consensus dialog, and high-throughput bulk CSV batch processing.

Scientific Integrity: Guarantees reliable, un-leaked evaluation metrics matching real-world editorial environments.

Section 02 • System Architecture & NLP Pipeline Slide 06 / 16

5-Stage Zero-Leakage Text Pipeline

Transforming raw natural language strings into numerical sparse feature vectors

01

Clean & Normalise

Lowercasing, regex stripping of HTML tags, punctuation, and URLs.

"apples new iphone 999"
02

Word Tokenize

Splits continuous sentence into discrete linguistic word units.

['apples', 'new', 'iphone', '999']
03

Stopword Pruning

Filters 179 high-frequency uninformative filler words (NLTK).

['apples', 'iphone', '999']
04

Lemmatization

WordNet morphologically reduces words to canonical base forms.

['apple', 'iphone', '999']
05

Sublinear TF-IDF

Unigrams + bigrams, max 10,000 features, sublinear term frequency scaling.

[0.42, 0.61, 0.28, ...]
Order of Operations: Text cleaning before tokenization reduces token array allocations by ~35%.
Section 03 • Machine Learning Models Slide 07 / 16

The 4 Machine Learning Models Explained

Benchmarking probabilistic, geometric, neural, and attention-based paradigms

1. Multinomial Naive Bayes

0.5 ms • 92.1% Acc

Multiplies word probabilities assuming conditional feature independence given class. Laplace smoothing (alpha=0.1) prevents zero-probability traps. Ultra-fast baseline with tiny memory footprint.

P(c_k | x) ∝ P(c_k) · ∏ P(x_i | c_k)

⭐ 2. Linear SVM (Champion)

1.2 ms • 96.4% Acc

Cover's Theorem states high-dimensional sparse text (10,000 features) is linearly separable. Finds the maximum-margin boundary without overfitting. Calibrated via Platt scaling.

min 1/2 ||w||^2 + C ∑ ξ_i

3. Neural MLP

3.2 ms • 95.1% Acc

Two dense layers with 128 hidden neurons, ReLU activations, and Adam optimizer. Learns non-linear word associations across news topics.

h = ReLU(W_1 · x + b_1)

4. DistilBERT Transformer

12.4 ms • 97.8% Acc

6 transformer layers, 66M parameters, bidirectional self-attention. Retains 97% of BERT's comprehension via knowledge distillation while running 60% faster.

Attention(Q, K, V) = softmax(QK^T / √d_k) · V
Theoretical Takeaway: High-dimensional sparsity gives Linear SVM transformer-grade accuracy in 1/10th the time.

Section 05 • Error Analysis & Explainability Slide 12 / 16

Opening the Black Box: Model Explainability

Transforming opaque machine learning predictions into auditable keyword saliency

1. Feature Coefficient Extraction (Linear SVM)

Mathematical Weights

Decisions follow f(x) = w^T · x + b. By multiplying word TF-IDF values by their hyperplane weights (w_i · x_i), NewsScope surfaces the exact tokens pulling the decision toward a category.

Example: 'processor' (+0.35) and 'macbook' (+0.28) strongly pull the prediction toward Technology.

2. Calibrated Confidence (Platt Scaling)

Statistical Probabilities

Standard SVMs output raw distance margins. Platt Scaling fits a logistic regression sigmoid on top of decision values, converting raw geometric margins into honest, trustworthy confidence percentages.

Example: Margin +2.45 -> 96.4% calibrated confidence percentage.

3. Interactive UI Saliency Badges

Editorial Validation

In our Next.js frontend, influential words light up with vibrant badges, giving editorial staff immediate visual confirmation of the classifier's reasoning before publishing recommendations.

Interpretability solves the adoption barrier in professional newsrooms.

Section 07 • Conclusion & Future Scope Slide 15 / 16

Current Limitations & Future Roadmap

Honest critical evaluation of system constraints and engineering roadmap

Current Limitations

  • • Historical Dataset: BBC 2005 corpus lacks modern vocabulary (smartphones, LLMs, cryptocurrency, streaming).
  • • Single-Label Constraint: Real-world stories frequently span multiple domains (e.g. Big Tech antitrust) but receive one label.
  • • Monolingual: Evaluated strictly on English language news articles.
  • • Static Retraining: No automated concept drift detection or continuous online retraining.

Future Roadmap

  • ✔ Multi-Label Classification: Binary relevance / sigmoid thresholding for multi-topic stories.
  • ✔ Multilingual Embeddings: Fine-tuning XLM-RoBERTa for cross-lingual news classification across 50+ languages.
  • ✔ Active Learning: Routing low-confidence predictions (< 50%) to editors for iterative labeling.
  • ✔ Model Quantization: 8-bit ONNX runtime deployment to achieve sub-millisecond transformer inference.
Roadmap items provide actionable continuity for postgraduate research and commercial deployment.
